# 600 Art Projects

An English, mobile-first members platform with 600 ready-to-teach art projects for Grades 1-8.

## Library

- 150 drawing projects
- 150 painting projects
- 150 collage projects
- 150 sculpture and 3D projects

Each activity includes a learning objective, grade recommendation, materials, preparation, detailed steps, teaching guidance, assessment, differentiation, a low-material alternative, and an editable DOCX download.

## Local preview

Serve this directory with any static web server, for example:

```sh
python3 -m http.server 8769
```
